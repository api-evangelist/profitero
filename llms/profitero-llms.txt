# Profitero (Profitero+)

> Profitero+ is an eCommerce data, technology and services platform that helps consumer
> brands measure and grow their digital shelf presence across retailers such as Amazon,
> Walmart, Tesco and Target. It combines digital shelf analytics, sales & share
> measurement, content optimisation, retail media activation (Shelf Intelligent Media)
> and managed services. Founded 2010, Dublin/Boston; acquired by Publicis Groupe in
> March 2022 and operated within Publicis Commerce.

## API status

- **No public API contract.** Profitero publishes no developer portal, no API reference,
  no OpenAPI / AsyncAPI / GraphQL SDL, no Postman collection, no MCP server and no A2A
  agent card on any public host.
- **An API exists, but it is a partner API and it is not documented publicly.** Profitero's
  own CEO Bryan Wiener stated it on the company blog (2020-09-09): *"Technology partners,
  like Kenshoo and Pacvue, will be able to integrate directly with Profitero via API and use
  the data to power their ad buying algorithms and software"*, and *"We will also consider
  providing API access to agencies in Q4."* No base URL, authentication model, operation
  list or specification for that API appears anywhere a member of the public can reach.
- **The route to it is a sales conversation.** Access runs through the Open Commerce
  Ecosystem partner programme (https://www.profitero.com/open-commerce-ecosystem) and the
  demo request form (https://www.profitero.com/request-a-demo). There is no self-serve
  sign-up and no published pricing.
- **Do not confuse Profitero's API with the APIs it consumes.** Profitero is a heavy
  CONSUMER of other companies' APIs — the Amazon Selling Partner (SP) API (its "Recovery by
  Profitero" product asks sellers to authorise SP-API credentials), the Amazon Ads bid
  modifiers API, and Walmart's partner APIs. Those are Amazon's and Walmart's contracts,
  not Profitero's.
